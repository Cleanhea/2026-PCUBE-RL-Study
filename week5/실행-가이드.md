## 0. 버전 (맞춰야 함)

| | 버전 |
|---|---|
| Unity | 6000.3.12f1 (프로젝트 그대로) |
| Unity 패키지 | `com.unity.ml-agents` **4.1.0** (manifest에 이미 추가됨) |
| Python | **3.10.x** (3.10.12 권장) |
| pip | `mlagents==1.1.0` |

> **왜 4.1.0인가:** Unity 6.1+ 에선 추론 백엔드가 Sentis → **Inference Engine**(`com.unity.ai.inference`)로
> 바뀌었다. 구버전 `com.unity.ml-agents` 3.0.0은 사라진 `Unity.Sentis`를 참조해 **컴파일이 안 된다.**
> 4.1.0이 Inference Engine을 쓴다. 패키지 임포트 시 `com.unity.ai.inference`가 의존성으로 함께 깔린다.
>
> **pip는 1.1.0 그대로:** Unity↔Python gRPC 통신 프로토콜(`k_ApiVersion` 1.5.0)은 4.1.0에서도 동일해서
> PyPI 최신인 `mlagents 1.1.0`(프로토콜 1.5.0)과 그대로 호환된다. C# 패키지만 올리면 된다.

## 1. Python 환경 (한 번만)

```bash
conda create -n mlagents python=3.10.12 -y
conda activate mlagents
pip install mlagents==1.1.0
mlagents-learn --help      # 설치 확인
```

## 2. Unity: 패키지 임포트 + 컴파일 확인

1. `week5/TetrisAgent` 프로젝트를 Unity Hub로 연다. → manifest의 `com.unity.ml-agents`를
   자동으로 내려받아 임포트한다(의존 패키지 Inference Engine `com.unity.ai.inference` 포함, 몇 분 걸릴 수 있음).
2. **Console(오류 0개) 확인.** `TetrisMLAgent.cs`는 ML-Agents 임포트가 끝나야 컴파일된다.
   빨간 에러가 있으면 여기서 멈추고 해결.

## 3. 씬 세팅 (`Assets/Scenes/TetrisTrain.unity`) — **이미 배선됨, 확인만**

`TetrisAgent` 오브젝트가 씬에 이미 만들어져 있고 아래 값으로 설정돼 있다. Inspector에서 확인만 하면 된다.

- **TetrisMLAgent** — `View Board` = TetrisBoard(관전용, 씬의 보드는 `autoPlay=false`)
- **Behavior Parameters** — Behavior Name=**`Tetris`**(yaml 키와 동일), Space Size=**214**,
  Continuous=**0**, Discrete Branch 0 Size=**40**, Model 비움, Behavior Type=Default
- **Decision Requester** — Decision Period=**1**

> (선택, 병렬 수집) `TetrisAgent` 오브젝트를 여러 개 복제하면 경험 수집이 빨라진다.
> 관전 보드는 하나만 연결(나머지는 View Board 비움).

## 4. 학습 실행

```bash
cd week5              # configs/ 가 보이는 위치
mlagents-learn configs/tetris_sac.yaml --run-id=tetris_sac_01
# "Start training by pressing Play in the Unity Editor" 뜨면 → 에디터에서 ▶ Play
```

- 이어서: `--resume` / 덮어쓰기: `--force`
- 속도: 에디터 우상단 Timescale ↑ (또는 `--time-scale`). 관전할 땐 1 유지.
- **초반 `buffer_init_steps`(2000) 동안 보상이 안 움직여도 정상** — 랜덤 수집 구간.

## 5. 지표 보기

```bash
tensorboard --logdir results
```
`Environment/Cumulative Reward`(우상향?), `Policy/Entropy`(감소?), `Losses/*` 먼저 확인.

## 보상 설계 메모 (`TetrisMLAgent.cs`, Inspector에서 튜닝 가능)

- 생존 +0.01 / 라인 [0,.1,.3,.6,1.0] (테트리스 비선형 우대) / 게임오버 −1
- shaping: 배치 후 **구멍·최대높이·bumpiness의 증가분만** 벌점(줄면 벌점 없음)
- 무효 액션은 마스킹으로 차단, 그래도 나오면(놓을 곳 없음=탑아웃) 게임오버 처리
- SAC는 보상 스케일에 민감 → 전체를 대략 [−1, +1]로 유지
