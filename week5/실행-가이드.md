# 테트리스 SAC 학습 — 실행 가이드

`TetrisMLAgent.cs`(에이전트), `configs/tetris_sac.yaml`(SAC 설정), ML-Agents 패키지까지
코드/설정은 다 들어가 있다. 아래 순서대로 하면 **학습이 돈다.**

이론/설계 배경은 [TetrisAgent.md](./TetrisAgent.md), [이론-SAC.md](./이론-SAC.md) 참고.

| | 버전 |

## 1. Python 환경 (한 번만)

```bash
conda create -n mlagents python=3.10.12 -y
conda activate mlagents
pip install mlagents==1.1.0
mlagents-learn --help      # 설치 확인
```

## 2. Unity: 패키지 임포트 + 컴파일 확인

1. `week5/TetrisAgent` 프로젝트를 Unity Hub로 연다. → manifest의 `com.unity.ml-agents`를
   자동으로 내려받아 임포트한다(의존 패키지 Sentis 포함, 몇 분 걸릴 수 있음).
2. **Console(오류 0개) 확인.** `TetrisMLAgent.cs`는 ML-Agents 임포트가 끝나야 컴파일된다.
   빨간 에러가 있으면 여기서 멈추고 해결.

## 3. 씬 세팅 (`Assets/Scenes/TetrisTrain.unity`)

이 부분만 에디터에서 손으로 붙인다. `BehaviorParameters`는 패키지 컴포넌트라
씬에 미리 직렬화해 두면 버전에 따라 깨질 수 있어 일부러 남겨 뒀다.

1. **빈 GameObject 생성** → 이름 `TetrisAgent` → `TetrisMLAgent` 스크립트 추가.
   (같은 오브젝트에 **Behavior Parameters**가 자동으로 붙는다 — `Agent`의 RequireComponent)
2. **Behavior Parameters** 설정:
   - Behavior Name = **`Tetris`** ← yaml의 `behaviors:` 키와 반드시 동일
   - Vector Observation > **Space Size = 214**
   - Actions > **Continuous Actions = 0**
   - Actions > **Discrete Branches = 1**, **Branch 0 Size = 40**
   - Model = 비움, Behavior Type = **Default**
3. **Add Component → Decision Requester**, **Decision Period = 1**.
4. (선택, 관전) Hierarchy의 **TetrisBoard**를 `TetrisMLAgent`의 **View Board** 슬롯에 드래그.
   씬의 TetrisBoard는 이미 `autoPlay = false`(관전 모드)로 맞춰 뒀다.
5. (선택, 병렬 수집) `TetrisAgent` 오브젝트를 여러 개 복제하면 경험 수집이 빨라진다.
   관전 보드는 하나만 연결(나머지는 View Board 비움).

## 4. 학습 실행

```bash
cd week5              # configs/ 가 보이는 위치
mlagents-learn configs/tetris_sac.yaml --run-id=tetris_sac_01
# "Start training by pressing Play in the Unity Editor" 뜨면 → 에디터에서 ▶ Play
```

- 이어서: `--resume` / 덮어쓰기: `--force`
- 속도: 에디터 우상단 Timescale ↑ (또는 `--time-scale`). 관전할 땐 1 유지.
- **초반 `buffer_init_steps`(2000) 동안 보상이 안 움직여도 정상** — 랜덤 수집 구간.

## 5. 지표 보기

```bash
tensorboard --logdir results
```
`Environment/Cumulative Reward`(우상향?), `Policy/Entropy`(감소?), `Losses/*` 먼저 확인.

## 6. 학습된 모델로 플레이(추론)

1. `results/tetris_sac_01/Tetris.onnx` 생성됨.
2. Behavior Parameters의 **Model**에 그 `.onnx` 할당, **Behavior Type = Inference Only**.
3. View Board 연결해 두면 그대로 관전 가능.

## 보상 설계 메모 (`TetrisMLAgent.cs`, Inspector에서 튜닝 가능)

- 생존 +0.01 / 라인 [0,.1,.3,.6,1.0] (테트리스 비선형 우대) / 게임오버 −1
- shaping: 배치 후 **구멍·최대높이·bumpiness의 증가분만** 벌점(줄면 벌점 없음)
- 무효 액션은 마스킹으로 차단, 그래도 나오면(놓을 곳 없음=탑아웃) 게임오버 처리
- SAC는 보상 스케일에 민감 → 전체를 대략 [−1, +1]로 유지
